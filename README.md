# J.A.R.V.I.S. — Локальный Мультимодальный ИИ-Ассистент для Android

Полностью автономное Android-приложение на **Kotlin + Jetpack Compose + C++ JNI (`llama.cpp` + `mtmd`)** под твою обученную модель `Qwen3.5-2B.Q4_K_M.gguf` и модуль зрения `Qwen3.5-2B.F16-mmproj.gguf`.

## Что внутри
- **Локальный мультимодальный движок (`llama.cpp` + `mtmd`)**: работает прямо внутри APK без Termux, с поддержкой как зрения (фото и кадры из MP4 Reels), так и чисто текстового режима.
- **Защита от переполнения ОЗУ**:
  - Автокопирование `.gguf` во внутреннюю память приложения (`filesDir/models/`) для быстрого `mmap` без тормозов папки `Download`.
  - Автосжатие фото и видеокадров до `336px` (настраивается: `252 / 336 / 448px`) с выравниванием под сетку Qwen-VL.
  - Отключён `warmup` проектора, чтобы не было скачка памяти при загрузке.
  - Переключатель **«Включить зрение»** и выбор контекста (`512–2048`) прямо в интерфейсе.
  - Живой индикатор свободной ОЗУ в шапке.
- **Голос и кнопка**:
  - Центральная анимированная кнопка-ядро **Jarvis Orb** (реагирует на громкость голоса, статус мышления и озвучки).
  - Встроенный голосовой ввод (RU `SpeechRecognizer`) и голосовой вывод (RU `TextToSpeech`), который автоматически читает поле `speech` из JSON-ответа Джарвиса.
- **Парсер JSON-команд**: красиво отделяет голосовую реплику `speech` от карточки действия `ACTION` + раскрываемого `payload` с кнопкой копирования JSON.

## Как собрать APK через GitHub Actions
1. Создай новый репозиторий на GitHub (например, `jarvis-ai-android`).
2. Распакуй этот ZIP и залей все файлы в корень репозитория (включая папку `.github/workflows/build.yml`).
3. Открой вкладку **Actions** на GitHub — сборка `Build JarvisAI Android APK` запустится автоматически (сама скачает свежий `llama.cpp`, скомпилирует нативный C++ `arm64-v8a` движок и соберёт APK за ~6–9 минут).
4. Скачай готовый артефакт **`JarvisAI-debug-apk`** и установи на телефон.

## Первый запуск на телефоне
1. Открой **J.A.R.V.I.S.** → нажми на кнопку **Настройки** (правый верхний угол).
2. Выбери **`Qwen3.5-2B.Q4_K_M.gguf`** из папки `Download` — приложение один раз скопирует его внутрь себя.
3. Выбери **`Qwen3.5-2B.F16-mmproj.gguf`** для зрения.
4. Нажми **«Загрузить ИИ»** (если с включённым зрением телефону тяжело — просто выключи тумблер «Включить зрение» или поставь контекст `512` и кадр `252px`).
